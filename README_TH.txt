InPense - Android V1

ฟังก์ชัน
- บันทึกรายรับ / รายจ่าย
- วันที่ / ประเภท / หมวดหมู่ / จำนวนเงิน / หมายเหตุ
- สรุปรายรับ / รายจ่าย / คงเหลือ
- รายการล่าสุด
- กดค้างรายการเพื่อลบ
- ข้อมูลเก็บใน SQLite ภายในโทรศัพท์
- โลโก้ eX และลายเซ็น created by :: eXcaLite ::

วิธี Build APK
1. ติดตั้ง Android Studio
2. เปิดโฟลเดอร์ eX_MoneyBook_Android
3. รอ Gradle Sync
4. เมนู Build > Build Bundle(s) / APK(s) > Build APK(s)
5. APK จะอยู่ที่ app/build/outputs/apk/debug/app-debug.apk

หมายเหตุ:
โปรเจกต์นี้ไม่ใช้ไลบรารีภายนอก เพื่อให้ง่ายต่อการ Build และลดปัญหา dependency
