InPense Android V2.6
created by :: eXcaLite ::

ฐานอ้างอิง: Windows InPense V3.6

ตรงกับ Windows:
- รายรับ = น้ำเงิน
- รายจ่าย = แดง
- คงเหลือ = เขียว
- หมวดรายรับ:
  เงินเดือน, กำไรเทรด, โบนัส, ขายของ, ดอกเบี้ย,
  เงินคืน/รีเบต, รายได้เสริม, ของขวัญ/เงินให้, อื่นๆ
- หมวดรายจ่าย:
  อาหาร, ค่าน้ำ, ค่าไฟ, ค่าเน็ต, ค่าโทรศัพท์, ค่าเช่าบ้าน,
  เดินทาง, ช้อปปิ้ง, สุขภาพ, เทรด, ธรรมเนียม, การศึกษา, อื่นๆ
- เพิ่มรายการเองได้
- ลบเฉพาะรายการที่เพิ่มเองได้
- รายการมาตรฐานลบไม่ได้
- Search หมายเหตุ / หมวด / ประเภท / จำนวนเงิน / วันที่
- Filter ทั้งหมด/รายรับ/รายจ่าย + วันนี้/เดือนนี้/ปีนี้
- Supabase Sync + Auto Sync เดิมอยู่ครบ
- Logo / App Name เปลี่ยนเป็น InPense

สำคัญ:
- package ยังเป็น com.excalite.moneybook เพื่อใช้ฐาน/การเชื่อมต่อเดิมต่อ
- workflow ปัจจุบัน build แบบ Debug เพื่อให้ GitHub Actions สร้าง APK ได้ทันที
- ถ้าจะให้อัปเดต APK ทับรุ่นเดิมได้ถาวร ต้องตั้ง Release Signing Key แบบคงที่แยกต่างหาก
